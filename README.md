# Lingual Étude - Ami Studio

Обновлено: 20 августа 2026 года

Full-stack pet-проект для онлайн-школы английского языка. В одном веб-приложении объединены презентационный сайт, запись на занятия, авторизация, личный кабинет ученика и панель управления преподавателя.

Проект демонстрирует опыт проектирования пользовательских сценариев, разработки адаптивных интерфейсов, интеграции frontend-приложения с Backend-as-a-Service и настройки непрерывного деплоя.

Рабочий продукт: [amistudios.ru](https://amistudios.ru)

![Главная страница Ami Studio](docs/screenshots/01-manifest.webp)

## О проекте

Ami Studio построен вокруг полного пути пользователя: знакомство с подходом преподавателя, выбор формата обучения, запись, регистрация и дальнейшая работа с учебными материалами в закрытом кабинете.

Визуальная система сочетает редакционную типографику, спокойную цветовую палитру, крупные смысловые блоки и адаптивную композицию. Интерфейс доступен на русском и английском языках.

## Реализовано

- двуязычный адаптивный лендинг с авторской визуальной системой;
- продуктовые страницы с форматами обучения, отзывами, FAQ и формой заявки;
- регистрация, вход по email или через Google и восстановление пароля;
- защищённый личный кабинет ученика;
- расписание, видеоуроки, домашние задания, статусы и обратная связь;
- ролевая модель доступа для учеников и администраторов;
- панель преподавателя для управления учениками и учебными материалами;
- загрузка изображений и видео в облачное хранилище;
- интеграция с Supabase Authentication, Database и Storage;
- автоматическая публикация production-сборки на собственном домене.

## Технические решения

| Задача | Реализация |
| --- | --- |
| Архитектура интерфейса | React, компонентный подход и маршрутизация через React Router |
| Дизайн-система | Tailwind CSS, Radix UI и переиспользуемые UI-компоненты |
| Данные и кеширование | Supabase и TanStack Query |
| Авторизация | Email/password и Google OAuth через Supabase Authentication |
| Разграничение доступа | Роли `user` и `admin`, защищённые маршруты и политики Row Level Security |
| Работа с файлами | Загрузка обложек и видео в Supabase Storage |
| Пользовательский опыт | Адаптивная вёрстка, анимации Framer Motion и двуязычный интерфейс |
| Доставка продукта | GitHub Actions, GitHub Pages и пользовательский домен |

## Панель управления преподавателя

Администратор получает отдельный раздел управления внутри личного кабинета. На обзорном экране собраны ближайшее занятие, прогресс учеников, домашние задания и архив видеоуроков.

Административный доступ не привязан к личной учётной записи владельца. Операционное управление продуктом можно передать другой стороне через отдельный аккаунт с ролью `admin`, а затем отозвать или переназначить права без передачи персональных данных и основного аккаунта владельца.

![Обзор личного кабинета администратора](docs/screenshots/08-admin-overview.webp)

Преподаватель может выбрать ученика, сформулировать задание, связать его с темой занятия, установить срок выполнения и оставить обратную связь после проверки.

![Назначение домашнего задания](docs/screenshots/09-admin-homework.webp)

Видеоуроки назначаются конкретному ученику. Для каждого материала предусмотрены модуль, название, продолжительность, описание, обложка и видеофайл.

![Назначение видеоурока](docs/screenshots/10-admin-video-lessons.webp)
